# Dart list exercises

Both functions are defined in `bin/dart_exercise.dart`:

- `evens` returns the even numbers in their original order.
- `maxOf` returns the largest number, or `null` for an empty list.

Run the examples:

```sh
dart run
```

Expected output:

```text
[2, 4, 6]
9
[]
null
[]
-3
[-4, 0, 6]
5
```
